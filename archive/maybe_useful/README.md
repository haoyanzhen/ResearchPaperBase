# 或许有用的独立逻辑存档

版本：v1.0  
日期：2026-10-16

本目录是从旧应用独立提取的候选材料，不是新应用、SDK 或已验收核心。没有启动入口、数据库迁移、HTTP 服务、任务队列或全局业务配置。新项目不得为了使用某个片段而恢复旧接口或旧工程。

## 内容

| 子目录 | 内容 | 使用限制 |
| --- | --- | --- |
| `agent_logic/` | JSON 解析、Provider 字段映射、引用过滤、邮件布局片段及离线样例 | 只提供局部处理，不负责检索、身份合并、发布、发送或证据真实性 |
| `support_logic/` | 独立辅助候选及身份/配置业务规则材料 | 不构成认证、授权、配置仓储或会话实现 |
| `ui_materials/` | 少量纯展示/格式化素材及有效交互测试场景 | 不保留旧页面、接口、路由和状态管理 |

## 两类处置

- **或许有用：**仅本目录的限定材料。来源、修改与测试见各子目录说明；复用时仍须满足新契约。
- **危险无用：**旧应用源码、旧接口与装配、旧迁移、旧测试和运行配置。其完整文件删除，不在存档中复制旧应用。这里的名称表示不宜继承，并非断言每一行都存在安全漏洞。

代码处置与源文件哈希见 [清理清单](../../docs/workorders/legacy_cleanup_manifest_2026-10-16.json)，审查依据见 [独立审查](../../docs/proposals/reuse_independent_review_2026-10-16.md)。原路径只作为来源记录，不表示文件仍存在。既有 Git 历史未改写。

## 使用约束

先读取子目录说明，显式选择片段，在新需求下补测试再采用。不要把本目录加入默认应用导入路径或自动发现的迁移/任务入口。离线样例通过不证明真实 Provider、真实邮件、生产认证或端到端业务正确。未实现任何新核心。

密码候选如需第三方依赖，应在将来的独立环境中核验；不恢复旧依赖全集。运行其他离线样例也应避免生成持久缓存。
