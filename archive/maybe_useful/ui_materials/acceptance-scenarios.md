# 或许有用：重建时的有效验收场景

版本：v1.0；日期：2026-10-16。来源为 `docs/proposals/reuse_independent_review_2026-10-16.md` 第 6、7 节及其中列出的旧测试。这里只保留可观察规则，不保留旧测试实现；以下均为待新契约确认与实现的场景，不是本轮通过记录。

| 来源 | 输入或触发 | 应观察的结果 |
| --- | --- | --- |
| T-R01 | 普通 JSON、外围 fence、数组、非法或超大输入 | 正确解码或明确失败；正文 fence 不被任意删除，结果另做 Schema 校验 |
| T-R02 | ID、序列化、分类错误、含嵌套秘密的诊断 | 符合新契约；安全响应不含秘密；随机样本无碰撞不能替代数据库唯一约束 |
| T-R03/06 | 普通用户读取/修改系统设置，跨 Project 读取正文/文件/诊断 | 明确拒绝并且无数据泄漏；成功状态不得作为允许结果；隐藏按钮不替代服务端授权 |
| T-R04 | 构建失败、迟到 Worker、失去写资格、并发发布 | 故障归属正确 attempt；既有成功成果和人工编辑不受污染；失败不发布知识版本 |
| T-R05 | 用户提交问题后 LLM 故障 | 保留用户输入、失败 attempt 和安全诊断；不能以 Turn 数不变证明正确 |
| T-R07 | 独立测试库初始化、服务内部 commit、后台任务结束 | 环境与业务库隔离；清理覆盖已提交写入及后台任务；不得回退业务 DATABASE_URL |
| T-R08 / F-R01/03 | 登出后身份查询返回、切账号、401、临时网络失败、重复登录提交 | 迟到结果不恢复旧身份；网络失败与身份失效区别展示；重复提交受控；登录目标 query/hash 可恢复 |
| T-R08 / F-R04 | 独立设置区保存失败、未保存编辑、收件人重复、秘密更新/清除 | 一处失败不清除其他编辑；收件人解析校验去重；秘密仅展示配置状态，不返回值 |
| T-R08 / F-R05 | 依赖部分失败、未配置、加载中、读取失败 | 各项结果分别可见；unknown/error/loading 区分；连通不被当成可用；探针不暗中发邮件或付费生成 |
| T-R08 / F-R06 | 项目表单关闭重开后旧请求返回；空白名称；重复提交 | 新表单不被迟到结果污染；错误保留有效输入；无重复创建 |
| T-R09 | 查询历史晚于已收回复片段返回 | 按 ResponseAttempt 身份合并，迟到快照不覆盖新片段；不能自动改绑知识版本 |
| T-R10 / F-R07/08 | 切 Project/Run、权限降级、导航、人工编辑后收到自动建议 | 旧私有诊断不残留；导航不提交模式切换；建议不能静默覆盖人工编辑；关闭/取消结果可观察 |
| F-R02/09 | 204、非法 JSON、错误响应、特殊路径参数、下载文件名 | 不把错误响应下载成产物；filename/filename* 正确解释，资源释放；类型断言不能替代验证 |
| F-R10 | SSE CRLF、跨块中文字节、多行 data、异常断流 | 正确解析；EOF 不等于业务成功；消费绑定正确对象；去重/恢复按新分期契约验收 |
| F-R11 | 打开/关闭对话框、Esc、键盘遍历、未保存修改 | 焦点捕获并恢复；背景隔离；未保存修改提示；读屏语义正确 |
| T-R11 | 登录→手动构建→研究→综述，以及诊断与失败路径 | 使用确定性数据和真正被后端调用的假 Provider；断言业务结果与失败状态，缺元素不能跳过；无额外 EventSource 冒充产品订阅 |

后续新测试必须按新业务契约编写；不继承旧阶段编号、mode/status、接口字段或 fixture。旧 mock、旧锁文件、旧运行入口不属于这些规则的依赖。
