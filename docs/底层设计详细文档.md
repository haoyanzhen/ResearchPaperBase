## 2. 双模式设计架构

### 2.1 模式对比

| 特性 | 构建模式 | 深度研究模式 |
|------|---------|-------------|
| **目标** | 快速构建知识库 | 深度探讨与创新 |
| **检索方式** | 关键词检索 | Graph-RAG知识图谱检索 |
| **LLM交互** | 任务导向 | 对话式探讨 |
| **数据来源** | 学术数据库 | 学术数据库 + 网络搜索 + 用户输入 |
| **Agent角色** | 执行者 | 研究助手 |
| **用户参与度** | 低（配置为主） | 高（持续对话） |
| **输出形式** | 论文列表 + 分析报告 | 研究结论 + 实验设计 + 创新方向 |
| **适用场景** | 文献收集、现状调研 | 理论研究、技术突破 |

#### 2.2.2 模式验证器

```python
class ModeValidator:
    """模式验证器 - 确保模式的互斥性和完整性"""

    @staticmethod
    def validate_mode_exclusivity(current_mode: ResearchMode, new_mode: ResearchMode):
        """验证模式互斥性：同一时间只能处于一种模式"""
        if current_mode == new_mode:
            return True  # 同一模式，无需切换

        # 检查是否可以切换
        # 1. 保存当前模式的状态
        # 2. 验证新模式的完整性
        # 3. 执行切换操作
        return True

    @staticmethod
    def validate_mode_completeness(mode: ResearchMode):
        """验证模式完整性：必须处于一种模式中，不能处于"无模式"状态"""
        if mode is None:
            raise ValueError("研究主题必须处于一种模式中")
        return True
```

#### 2.2.3 模式切换器

```python
class ModeSwitcher:
    """模式切换器 - 负责模式切换和状态管理"""

    def __init__(self, project_id: str):
        self.project_id = project_id
        self.current_mode: ResearchMode = None
        self.mode_state = {}  # 存储不同模式的状态

    def switch_to_mode(self, new_mode: ResearchMode):
        """切换到新模式"""
        # 1. 验证模式互斥性
        if not ModeValidator.validate_mode_exclusivity(self.current_mode, new_mode):
            raise ValueError(f"无法从{self.current_mode}切换到{new_mode}")

        # 2. 保存当前模式的状态
        if self.current_mode is not None:
            self._save_current_mode_state()

        # 3. 初始化新模式的状态
        self._initialize_mode_state(new_mode)

        # 4. 更新当前模式
        self.current_mode = new_mode

        # 5. 验证模式完整性
        ModeValidator.validate_mode_completeness(self.current_mode)

        return True

    def _save_current_mode_state(self):
        """保存当前模式的状态"""
        mode = self.current_mode.value
        # 保存状态到数据库或内存
        self.mode_state[mode] = {
            'timestamp': datetime.now(),
            'data': self._get_current_mode_data()
        }

    def _initialize_mode_state(self, mode: ResearchMode):
        """初始化新模式的状态"""
        mode_value = mode.value
        if mode_value not in self.mode_state:
            # 如果是第一次进入该模式，初始化状态
            self.mode_state[mode_value] = {
                'timestamp': datetime.now(),
                'data': {}
            }
        else:
            # 如果之前进入过该模式，恢复状态
            self._restore_mode_state(mode)

    def _get_current_mode_data(self):
        """获取当前模式的数据"""
        # 根据当前模式获取相应的数据
        if self.current_mode == ResearchMode.CONSTRUCTION:
            return self._get_construction_mode_data()
        elif self.current_mode == ResearchMode.DEEP_RESEARCH:
            return self._get_deep_research_mode_data()

        """恢复模式状态"""
        mode_value = mode.value
        state = self.mode_state[mode_value]
        # 恢复状态
        if mode == ResearchMode.CONSTRUCTION:
            self._restore_construction_mode_state(state['data'])
        elif mode == ResearchMode.DEEP_RESEARCH:
            self._restore_deep_research_mode_state(state['data'])

            'search_queries': [],
```

### 2.3 模式扩展性设计

#### 2.3.1 扩展性原则

1. **枚举类型设计**：使用Enum类型定义模式，便于扩展
2. **策略模式**：不同模式对应不同的策略类，易于添加新模式
3. **上下文隔离**：每种模式有独立的上下文管理，互不干扰
4. **状态持久化**：模式切换时自动保存和恢复状态

#### 2.3.3 模式控制器工厂

```python
class ModeControllerFactory:
    """模式控制器工厂"""

    _controllers = {
        ResearchMode.CONSTRUCTION: ConstructionModeController,
        ResearchMode.DEEP_RESEARCH: DeepResearchModeController
    }

    @classmethod
    def get_controller(cls, mode: ResearchMode, project_id: str) -> ModeController:
        """获取指定模式的控制器"""
        controller_class = cls._controllers.get(mode)
        if controller_class is None:
            raise ValueError(f"未找到模式 {mode} 的控制器")
        return controller_class(project_id)

    @classmethod
    def register_controller(cls, mode: ResearchMode, controller_class: type):
        """注册新的模式控制器"""
        cls._controllers[mode] = controller_class
```

```python
# 模式上下文管理
class ModeContextManager:
    """模式上下文管理器"""

    def __init__(self):
        self.contexts: Dict[str, dict] = {}

    def get_context(self, project_id: int) -> dict:
        """获取项目的上下文"""
        project_key = f"project_{project_id}"
        return self.contexts.get(project_key, {})

    def update_context(self, project_id: int, context: dict):
        """更新项目的上下文"""
        project_key = f"project_{project_id}"
        self.contexts[project_key] = context

    def switch_mode_context(self, project_id: int, new_mode: str):
        """切换模式时更新上下文"""
        current_context = self.get_context(project_id)
        current_context['current_mode'] = new_mode
        self.update_context(project_id, current_context)

# 中间件：自动更新上下文
@app.middleware("http")
async def mode_context_middleware(request, call_next):
    """模式上下文中间件"""
    project_id = request.path_params.get('project_id')

    if project_id:
        context_manager = ModeContextManager()
        context = context_manager.get_context(project_id)
        request.state.mode_context = context

    response = await call_next(request)
    return response
```
