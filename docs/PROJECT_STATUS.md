## 1. 用途与维护规则

本文是项目进度和待完成项的统一入口。需求和业务规则以设计文档及人工裁决为准；详细执行证据保留在工作单、审查记录和测试报告中，本文只汇总并链接来源。

- 每次任务完成或范围、阻塞发生变化时，更新对应条目、证据、日期和文档次版本；新增事项使用稳定编号。
- 状态使用：待开始、进行中、待决策、延期、待核验、已完成、已过期。已过期表示不再作为当前有效基础；没有实际执行证据，不标为进行中或已完成。
- 设计完成与实现完成分开记录。实现完成须附相关代码、测试结果和验收范围；历史文档声明不等于本轮验证通过。
- 待办登记不代表已获执行授权；明确延期的事项继续保持延期。完成项保留，避免后续重复开展。
