- 状态使用：待开始、进行中、待决策、延期、待核验、已完成、已过期。已过期表示不再作为当前有效基础；没有实际执行证据，不标为进行中或已完成。

每日进度核对、当前文档同步及任务拆解维护遵循[每日整理规则](NIGHTLY_MAINTENANCE.md)。首次手动试跑与覆盖缺口见[整理记录](workorders/nightly_maintenance_2026-10-23.md)；[后续增量整理](workorders/nightly_maintenance_2026-10-23_0954.md)已核对5份证据文档增量，并建立FR-013的[task009规划](../tasks/009-workspace-context-plan.md)，实现与测试未启动；任务拆解的FR目录/开放TRACK归属不等于逐需求实现或测试覆盖完成。
