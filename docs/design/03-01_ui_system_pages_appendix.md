## 1. 布局与作用域

登录/注册、Project Hub、个人设置和管理员设置是独立系统页面，不嵌入 Project Workspace Shell。登录/注册不显示受保护导航；其他页面复用全局顶栏，不叠加 Project 对象栏或 Project Assets。进入设置不取消后台 Run 或流式回复；返回 Workspace 按主文上下文恢复规则处理。

设置页采用“设置分类 → 配置实例 → 编辑器”。分类与实例列表服务于不同层级，不复制 Project 导航；窄屏逐层进入，返回保留未提交输入，切换有未保存修改的实例时提供保存、放弃或留在当前页的选择，不自动覆盖。

P06a/P06b/P06c 分别为账户、LLM 和数据源；旧称 P07/P08/P09 分别映射 P06b/P06c/P06d，仅作为历史页号。当前 Agent 模型选择位于全局顶栏，配置实例编辑不切换运行中的模型快照。

P0 个人设置导航仅显示 Profile、LLM、Sources；P06d 为 FR-004 的 P1 参考页，启用该分期后才加入 Notifications。P0 管理员导航为 Users、LLM、Sources、SMTP、Security；P10f Backend 仅保留 P2 范围说明。SMTP 平台配置按 FR-006 保留，不代表 P0 已实现 FR-004 用户通知或 FR-027 业务推送。

#### P10f 管理员 / Backend（P2 范围占位）

P10a–P10e 使用同一级管理员侧栏。系统级 LLM、Sources、SMTP 和 Security 只影响平台默认配置和允许的硬限制，不允许管理员查看用户私人密钥明文；P1 硬限制不进入 P0 表单。
