# LLM扩展参数与首片实现契约

文档版本：v1.3
更新日期：2026-10-30
依据：01 FR002/007、08§12.2/12.3；用户2026-10-26接受task025参数方案并授权实现。

## 1. 已接受边界

常用类型化字段与受控custom_params分开；客户端超时不进入生成请求。只解析显式选中的配置，不引入账号/会话多层覆盖。未知模型可以保存协议结构合法配置并显式测试；协议编译通过不代表模型可用。仅当前配置/凭据修订下的逐模型显式成功允许新选择与新启动，发现/手填本身不授予可用性。已启动业务任务按08§12.3处理凭据更新。

参数字段唯一机器维护来源为contracts/p0.openapi.json；运行期协议允许列表与字段落点由版本化能力描述实现，前端不是授权来源。P0个人/系统LLM均无独立启停状态，数据源规则不变。

## 2. 参数结构与技术界限

常用字段为temperature、top_p、max_output_tokens、stop、seed、frequency_penalty、presence_penalty、top_k；适配器支持范围不同，未设置省略，不把0/false当空。custom_params接受已登记的生成字段，支持类型化标量/数组/对象；不接受任意请求体透传。协议枚举为openai_chat、openai_responses、anthropic_messages、gemini_content；DeepSeek按openai_chat，自定义连接仅在已实现兼容协议内选择。

结构校验上限为16KiB UTF-8参数JSON、嵌套深度6、每集合64项；拒绝重复键、非有限数字、布尔代替数字、未知字段及错误类型。同义字段或父子目标重复拒绝，不能按合并顺序覆盖。扩展对象只接受该描述登记的子字段；数组按整体值处理，不能隐式追加。

PATCH省略parameters保持；提供parameters对象整体替换，{}清空全部显式参数；null拒绝。对象内部省略即不再设置，不做多层隐式深合并。timeout_seconds为1–120秒，缺省30秒，与生成参数分开；部署限额只能收紧。具体Provider/模型限制仍由能力描述和显式测试反馈校验，不假称统一数值边界证明所有模型支持。

模型上下文容量是独立应用元数据`model_context_windows`（模型ID→总token容量），不放入parameters或发送给Provider。个人配置由本人修改，系统配置仍仅管理员修改。未配置模型默认262144 tokens（256K），用户可覆盖；这是用户声明值，不是连通测试验证的实际能力。每配置最多1000项，模型ID非空、无首尾空白、最多200字符，容量为1–2147483647的严格整数（不接受布尔值）。PATCH省略保持，提供映射整体替换，{}恢复所有模型默认，null拒绝；修改沿现有配置修订与逐模型重测规则。模型选项返回解析后的context_window_tokens。运行冻结所用配置，后续修改不静默改变已冻结容量；容量预算保留输入、输出及协议开销，Provider超限仍明确失败。D-PDF-03用户已于2026-10-30明确默认256K并允许修改，见[task047](../../tasks/047-llm-pdf-extraction-design.md)。

保留字段包括模型身份、messages/input/system/instructions、tools/tool_choice、stream、认证头/密钥/URL、账户/Project、路由/回调/文件目标和应用拥有的输出格式，均不可经custom_params覆盖。能力描述也不能重新登记受保护目标。错误只暴露字段与安全原因，不回显参数值或密钥。

## 3. 显式测试与结果

TestLLM请求增加model_id；刷新仍为空请求。不额外强制客户端修订；受理事务冻结已保存配置、model_id、配置/凭据修订。新增/测试/刷新持久幂等，同键同参数返回原对象或任务，失败同键不重新调用。配置级可用状态只作汇总，逐模型事实决定选择资格。

最小测试发送固定“Reply with the single word OK.”非业务文本，用户界面显示可能费用。保留用户显式参数，不静默删除或降级；Anthropic缺省未设置输出长度时测试采用32 token并在test_overrides展示。实际测试参数及覆盖单独记录，不据此证明全部流式/工具/大输出能力。测试读取、刷新结果、SSE及幂等重放均不触发Provider调用。

同修订同模型多次测试按受理时间/id的确定顺序选取已终结的最新测试结果；旧配置/凭据结果不授予新修订可选性。Worker崩溃或租约过期后已进入running的任务标为结果未知失败，不自动重发可能收费请求；queued任务可继续领取。结果和事件持久提交后才能查询/发送。任务无公开取消，不能把轮询UI作为虚假events_url的理由。

配置删除保留内部身份/历史但清除保存凭据，公开配置及其任务均按当前可见性拒绝；不改历史任务输入。当前已保存模型选择保留失效身份并提示修复，不自动回落。系统配置管理不在M-P0-05首片；不存在系统配置时不伪造系统模型选项。

## 4. 实现与验收分层

task026记录参数基础及个人配置闭环执行证据。必须覆盖逐参数编译/拒绝、协议实际请求映射、加密/无密钥回显、CRUD/修订/幂等、授权/禁用、迟到结果、Worker重复领取/恢复、事件回放、模型选择恢复、浏览器草稿/未知结果以及数据库迁移/清理。Provider默认mock；真实网络策略通过受控本地服务验证，不以mock声称真实云模型兼容。M-P0-05以完整个人配置业务成果提交，不能仅因参数测试通过而验收。

## 5. 首版能力登记与恢复实现

当前适配器以(protocol,api_version,model_id)定位能力。已登记OpenAI Chat o1/o3/o3-mini/o4-mini及代码列明日期快照的输出限额映射到max_completion_tokens，并拒绝不适用采样字段；其他名称/未登记API版本以未知能力处理，只做协议结构校验和显式测试，不宣称跨云兼容。依据[OpenAI Chat API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)关于max_tokens与o系列不兼容的说明（2026-10-26核对）；规则版本随适配器维护。配置保存用协议校验，测试受理再执行选中模型规则。

配置变更与凭据操作在同一事务写入不含值的审计记录；派发时将当前授权检查与出站请求提交排序，响应等待不占治理锁；过期返回不能标为成功。个人配置列表沿用PageMeta/page_size/cursor契约。公开任务错误复用现有PublicError，细分安全诊断放ConnectionTest.reason_code，不扩张公共错误词汇。

本地演示只使用显式隔离数据库，密钥保存在同一可清理目录的0600文件；重启复用密钥，后台Worker恢复queued，running租约过期后不重发。生产部署/完整管理员配置不属于本里程碑。

## 6. LLM文本整理引擎的输出缺省例外

2026-10-30 D-PDF-04用户明确选择：仅llm_text_cleanup引擎未填写输出上限时使用4096 tokens，并在启动说明及冻结配置中展示；所有已显式填写的输出上限（含合法同义参数）保持原样。该例外不改变连通测试、评分或其他调用的Provider缺省行为，也不写回个人配置。整理输入/输出预检使用冻结声明容量及保守估计，Provider溢出/截断仍失败，不声称精确token计数或完整视觉提取。
