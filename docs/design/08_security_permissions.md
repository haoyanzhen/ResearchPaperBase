# Security & Permissions 设计

文档版本：v1.1  
更新日期：2026-05-20  
依据文档：`00_layers.md`、`01_functional_requirements.md`

## 1. 设计目标

安全设计覆盖认证、授权、用户隔离、管理员边界、密钥保护、文件访问、archived 只读、审计和高风险操作确认。最终判定必须在后端 Application Use Cases 中完成。

## 2. 认证

- 注册时密码必须哈希存储。
- 登录可使用用户名或邮箱。
- 禁用账号不得登录。
- 已禁用账号的既有会话在下一次鉴权或刷新时失效。
- 公开入口仅包括登录、注册、找回密码、错误页等无需身份页面。

## 3. 权限模型

| 资源 | 普通用户 | 管理员 |
| --- | --- | --- |
| 自己的 Project | 可读写，受 Project 状态限制 | 不默认拥有，除非另有共享规则 |
| 其他用户 Project | 不可访问 | MVP 不提供越权查看 |
| 用户个人配置 | 仅本人可读写 | 不可查看私人密钥明文 |
| 系统配置 | 不可访问 | 可读写和测试 |
| 用户账号状态 | 仅本人基础信息 | 可启用、禁用、重置、授予/撤销管理员 |
| 观点 | 可发布/删除本人观点，查看公开观点 | 可隐藏观点 |

至少保留一个启用管理员，且并发变更时仍必须成立。

## 4. Project 状态权限

- `active`：允许正常读写。
- `paused`：允许手动交互，不参与自动调度。
- `archived`：默认只读；新建、启动、继续生成、上传、删除、重跑、刷新依赖等写操作拒绝。
- `deleted`：不可进入 Workspace，不参与调度。

导出历史内容可作为 archived 的允许动作，但仍需权限校验。

## 5. 密钥与配置安全

- API key、SMTP 密码和系统密钥不得明文存储、返回前端或写入日志。
- 运行时配置快照只保存来源、脱敏标识、模型/数据源名称和硬限制版本。
- 用户密钥只能被该用户任务使用。
- 系统密钥可作为回落能力，但普通用户不可读取明文。
- 管理员不得查看用户私人 LLM 或数据源密钥明文。

## 6. 文件访问安全

- PDF、解析文本、Graph 文件和导出文件通过对象 key 管理。
- API 只返回授权下载流或短期签名 URL。
- 过期、缺失、无权限、版本不匹配时返回安全空态。
- 不得暴露本地真实文件路径、桶内部路径或其他 Project 上下文。

## 7. 高风险操作

必须二次确认或显示影响范围：

- Project 归档、软删除和私人资产清理。
- 删除/禁用用户。
- 撤销管理员权限。
- 覆盖人工确认或人工修改内容。
- 手动触发会覆盖导出产物的再生成。
- 批量清理 PDF、向量索引、图谱或运行记录。

## 8. 审计

至少记录管理员用户治理、系统配置变更、Project 状态变更、软删除和私人资产清理、密钥配置创建/更新/删除的脱敏事件、内容覆盖确认、自动调度创建/跳过/失败、管理员隐藏观点。

审计字段包括操作者、目标类型、目标 ID、动作、结果、时间和脱敏元数据。

## 9. 安全测试入口

- 禁用用户既有会话拒绝。
- 非 owner 访问 Project 拒绝。
- 非管理员访问管理员接口拒绝。
- 最后管理员保护。
- archived 写操作拒绝。
- 文件 URL 越权与过期拒绝。
- 密钥不明文返回和不进入配置快照。
