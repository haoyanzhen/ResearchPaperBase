## 1. 设计目标

本文改为两类用例的统一入口：核心架构级用例验证跨模块不变量、并发、故障、契约与完整链路；功能模块级用例验证具体用户操作、状态前置和输出。它们是职责分类，不等于“单元测试/集成测试”层级；两类都可使用单元、契约、真实存储集成及端到端测试。

保留最小测试环境、断言、诊断和证据规则，不另建泛化质量平台。本文用例是验收设计，不是已运行测试；进度只在 PROJECT_STATUS 维护，测试报告保存于工作单或 CI 产物。既有 KV-I/KV-C/KV-V/API-R/领域S编号继续有效，不因重组丢失覆盖。

## 2. FR 闭环要求

每个实施范围内的 P0/P1 FR 子条目至少追踪到（整条 FR 的大分期不能覆盖其已批准 P0 子集）：

```text
UI / 后台入口
  -> Application Use Case
  -> Domain / Agent / Knowledge Rule
  -> Persistence or External Adapter
  -> AuthZ / State / Lock Check
  -> Test Case
  -> Diagnostic Signal
```

任务级规范映射、正负场景和人工审核字段统一使用[任务模板](../../tasks/example.md)，填写示例见[Project创建幂等](../../tasks/004-project-create-idempotency-example.md)。流程见[实施入口](../IMPLEMENTATION_ENTRY.md)；示例不是已运行测试，也不关闭全P0追踪。

### 4.1 不可变快照一致性验收

本表为后续自动化验收要求，非已执行结果。依据 [02-02 §2.5](02-02_construction_versioning_appendix.md#25-不可变逻辑快照与资产复用边界)、[06 §3.1](06_agent_knowledge_services.md#31-版本读取与存储适配契约)及 [07 §5.1–5.3](07_data_persistence.md#51-资产原子单元与修订闭包)。适用于 P0 知识链路；通用恢复、导出等扩展链路在对应 P1 实施时执行，不提前分期。

| 编号 | 场景 | 必须断言 |
| --- | --- | --- |
| KV-I01 | V12 任务检索后发布 V13，再读取正文/分析/图谱 | 全链路及子任务仍 V12，不能读到 V13 新论文或边 |
| KV-I02 | 两版复用 A，V13 在已发布移除后重新导入 B/分块/分析 | A 同修订复用；B 新修订；V12 内容、定位、元数据与校验值不变 |
| KV-I03 | 全局高分候选在 V13、V12 候选分数较低 | V12 在自身范围检索排序，不因先全局 top-k 再过滤丢失结果；图谱每步均过滤版本 |
| KV-I04 | 发布发生在分页/缓存/异步排队之间 | 游标、缓存和 Worker 均保持原解析版本；过期游标重开不默认升级；缓存命中后撤权仍拒绝 |
| KV-I05 | 外部写入失败、延迟可见、发布提交响应丢失 | 无半版本；只认一个发布决定；默认指针/Run/发布事件一致；孤立候选不被正式读取 |
| KV-I06 | 取得读取保护与清理交错；租约到期后旧 Worker 仍活跃 | 只有一方取得资格；保护失效后旧 Worker 不可继续读/提交；共享资产不被误删 |
| KV-I07 | 旧证据损坏、权限撤销、明确删除 | 安全失败及允许的诊断，不用新证据替换；不泄露其他 Project 内容 |
| KV-I08 | 引用 ID/定位跨版本复用、模型或切片配置变化 | 拒绝错误映射；不同派生输入不能当作未变产物复用 |
| KV-I09 | 适配器替换、调用缺少 ReadContext | 同等隔离与身份契约；能力不足或缺上下文则拒绝，不能降级为最新集合查询 |

实现时使用可控并发屏障和故障注入证明上述交错，不能只依靠顺序 mock 测试。数据库测试必须显式隔离，外部 LLM/论文/邮件默认 mock；真实存储适配验收使用明确的独立测试目标，不写业务库。接口契约测试和真实存储集成测试不能替代最终端到端验收。

### 4.2 引用有效性与版本选择验收

以下为设计验收要求，未执行实现测试；P0 基础引用/选择不将 FR-031 的 P1 图谱浏览增强或 P1 导出/恢复提前。相关扩展在原分期实施时覆盖。

| 编号 | 场景 | 断言 |
| --- | --- | --- |
| KV-C01 | V13 在移除后重新导入正文/切片或排除论文 | V12 引用仍定位原修订；旧版正常可读，不判失效 |
| KV-C02 | 两版共用正文，或仅 DOI 相同 | 新研究引用必须属于目标版；相同 DOI 不绕过修订/成员核验，原引用与确认不变 |
| KV-C03 | 同用户两个 Project、相同哈希、拼接证据 ID | 仍逐项检查 Project 与成员，拒绝跨项目注入/泄漏 |
| KV-C04 | 撤稿、更正、临时故障、永久缺失、凭据过期 | 风险与可读性独立；临时故障重试同证据，凭据重新鉴权不换修订；非成功沿用安全错误 |
| KV-C05 | 引用可解析但论断被编辑 | 不自动判定支持，不继承旧人工确认；未复核明确标记；不设严格覆盖率，学术支持问题只提供建议 |
| KV-V01 | 新建、继续、历史核查、采用更新 | 分别默认最新、绑定版、原证据版、显式目标新对象；浏览不改绑定 |
| KV-V02 | 已选 V13 后发布 V14 | 显式创建仍 V13；无指定版本才事务解析最新；目标不可用失败不换版 |
| KV-V03 | 累计版本、手工补充、revision_only、来源部分失败 | 本轮窗口不冒充累计完整覆盖；无新检索不刷新截止；失败/未知不显示为完成 |
| KV-V04 | 摘要降级、资料、未知统计、零成员 | 论文来源桶互斥且合计正确，资料分开；未知不当 0，不提供伪完整度/质量评分；空版可浏览并创建 Research/Review，提示无证据且不换版 |
| KV-V05 | 最新版本暂不可用/撤权、已有固定范围 | 不自动降级或泄漏版本摘要，允许显式选合法历史版；固定不屏蔽重要风险或冒充截止认证 |

契约测试覆盖 04-01 §5.1 条件必填及错误映射；UI 验证事实标签、绑定提示与并发发布选择；真实解析/存储及端到端验收须另行执行，文档检查不替代运行验收。

### 4.4 安全与交付细化用例

下表为既有ARC/MOD用例族的细化场景，不新增角色、功能或产品分期。统一使用第3节模板；适用P0核心，P1/P2操作仅在原分期执行。安全策略待决部分不假设通过，按08 §12和10 §9标记“待决策后补测”。

| ID / 复用入口 | 前置、动作及故障点 | 正负断言与证据 |
| --- | --- | --- |

## A09 Graph-RAG验收与评测样本

### A09.1 固定最小语料与数值反例

实施时建立隔离Project P/Q，各有固定版本V1/V2，所有内容为自编合成资料并保存UTF-8文件、摘要、处理定位与人工标注，不下载论文或上传真实用户资料。至少包含：P/V1公共论文A的原文“方法M在数据集D用于任务T”；公共资料B“数据集D的限制是噪声N”；公共论文C“方法M不使用数据集E”；私人批注X含一个更近向量及“方法M使用E”的矛盾；Q含同名方法M；P/V2新增D2或移除B。摘要降级文件F无PDF但有实际摘要，扫描无文本G不得混进有效文本。人工预期：问D的限制需B；问M是否用E须保留否定和来源矛盾，不盲信私人X或Graph路径；问V1不得引用D2。

两跳Graph示例：向量/词法种子只命中A，图A→method M←B的uses_method关系由各自原文支持（此场景另给B原文“方法M在噪声N下失效”）；应扩展召回B及其支持片段。此例和上一段D限制是独立夹具修订，不能让同一B无修改记录地换正文。图消融只启用向量/词法时缺B，混合链有B，才能证明图通道确实工作；真模型可能也直接召回B，故确定性端口夹具用于路径正确性，真实模型质量另评。

过滤反例固定距离：禁用X=.01、Q=.02、V2-only=.03，合法A=.20、B=.30，k=2必须得到A/B；全局top2再过滤为空应失败。同概念公共label+私人label只返回允许label；若A到B唯一桥的任一支持私人，则图不得走该桥，即使B正文公开。RRF独立数值例：rank1+rank2=1/61+1/62，缺分支贡献0，平局按ID。

预算例给生成模型context=4096、reserve=512、system+必需history=1024、本轮query+固定包装=256、margin=128、调用预算3000，则B=2176 token；证据路径本体+全部支持+引文成本超过B必须整体排除。有检索命中但没有一个完整项能装入时不是检索empty。另将本轮问题增加到2600 token，应预算失败而不是遗漏问题长度继续组包。emoji及中英混合span按Unicode码点验证，token长度按实际固定tokenizer单独验证，不互相替代。
