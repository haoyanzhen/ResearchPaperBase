- 平台资产与已完成测试/审计不随创建管理员删除；个人配置只归本人。密钥加密存储、不在配置响应、事件或解析结果中回显。
- 未知创建用原键恢复，未知更新只读核查；个人/系统页面分别保留草稿。390宽移动端页面已检查无横向溢出。

## 复现场景

按[README](../../README.md)选择Node24/Python3.14并运行build，然后用显式隔离PG demo入口：

```sh
python3 scripts/engineering.py build
python3 scripts/engineering.py demo --postgres-bin /opt/homebrew/opt/postgresql@17/bin
```

1. 首位用户注册为管理员，登录后打开“系统数据源”，新增arXiv配置并保存，切换/刷新后核对保存事实；启停、修改和删除均有修订保护。
2. 打开个人“数据源设置”，分别新增arXiv、OpenAlex、Semantic Scholar、ADS，配置各自API入口和适用密钥。刷新后切换四个配置，入口各自恢复、密钥不回显。
3. 显式连接测试须勾选外发提示，可能消耗真实服务额度；本轮自动验收仅使用FakeSource/受控本地服务。自动浏览器测试涵盖系统成功、禁用、私人隔离、未知响应与草稿恢复，避免为验收自动访问真实外部服务。
4. 逐Provider解析反例、撤权/并发/事务失败需通过任务单列出的隔离PG测试复现；目前没有Construction页面可替代这些内部接缝测试。
