## 交付范围与状态

承接用户接受 M-P0-06 后的继续授权，实现 FR-005 的当前账号治理闭环：管理员基础账号列表、修改邮箱、一次性密码重置、普通用户启用/禁用/删除，以及其他用户管理员授予/撤销。所有修改先预览并确认风险；账号治理不提供私人 Project 或配置读取权。

设计与代码已完成，独立审查问题全部修复；最终自动验证与 S1–S7 工程收口完成，M-P0-07 待人工验收。授权、检查点见 [task029](../../tasks/029-admin-accounts.md)。通知保持 P1，系统配置与知识构建不在本轮范围；未遇到新的未明确业务设计。

## 关键行为

- 身份、CSRF、目标修订、确认参数及真实影响摘要在同一账号治理锁下裁决。预览后新增私人资产或任务使旧删除确认失效，客户端只见安全治理摘要。
- 邮箱不能与其他账号的用户名或邮箱冲突。非管理员不能读取治理列表，角色变更不赋予私人内容访问权。
- 密码重置使用幂等命令；新密码只出现在首次成功响应，重放仅返回已重置事实及同一期限。已有会话撤销，自重置页面保留一次性密码供复制，不立即触发鉴权刷新。
- 禁用永久终结当前排队/在途配置测试资格；重新启用不能复活旧会话或旧任务。已有任务终态保持。
- 删除先持久撤销账号访问及任务资格，再清理当前 Project/ConstructionWorkspace、配置/凭据/任务等私人资产。清理失败保持失效；原请求可核查，也可重新确认删除继续清理，允许有效管理员接管。操作、接管及清理结果有独立安全审计。
- 清理只删除本人资源和私人速率记录，保留其他账号及 arXiv 全局速率预算。并发失败落账不能覆盖已完成清理状态。
- 未知 PATCH 结果读取当前账号核查，不重提旧修订。浏览器退出/刷新不持久保存新密码。

## 可复现验收

在仓库根目录执行：

```sh
npm --prefix frontend run build
python3 scripts/engineering.py demo --postgres-bin /opt/homebrew/opt/postgresql@17/bin
```

打开终端显示的本机 `/workspace`。首次注册账号为管理员；用另一浏览器隐私窗口注册普通账号。临时演示环境最多30分钟，退出后清理，不能用作持久业务数据库。

1. 管理员登录后打开“管理员用户”，普通用户没有此入口。列表只含基础账号信息。
2. 选择普通账号，修改邮箱；预览并勾选影响后确认。检查另一窗口中的当前邮箱。
3. 重置普通账号密码，复制首次显示的新密码；刷新后不再展示，旧密码/旧会话失效。
4. 禁用普通账号，再启用；旧会话仍失效，必须重新登录。
5. 授予另一账号管理员，再撤销；不可授撤自身角色，不开放管理员账号禁用/删除。
6. 普通账号创建一个Project及个人配置，然后确认删除；该账号失效，另一账号数据保留。
7. 丢失响应、失败清理及并发场景可运行下列自动测试复现，均使用本地隔离数据，不调用真实论文或邮件服务。

```sh
PYTEST_ADDOPTS='-k "test_ag or test_ab"' backend/.venv/bin/python scripts/run_storage_tests.py --postgres-bin /opt/homebrew/opt/postgresql@17/bin
python3 scripts/engineering.py check
```
