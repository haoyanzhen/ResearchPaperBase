## 可观察行为及关键边界

- 管理员打开“系统LLM”进行CRUD、加密凭据set/clear和类型化参数编辑；保存不调用Provider，LLM没有独立启停开关。
- 模型发现和手填仅产生候选；勾选费用提示后显式测试，当前配置/凭据修订下逐模型成功才可选择。系统/个人来源明确标注，未选择时不自动使用系统模型。
- 普通用户不能访问系统配置/测试任务/凭据，仅能获取安全模型选项。当前管理员可管理平台配置和读取系统测试，不能因此读取其他用户私人配置/任务。
- 配置修改、凭据轮换或删除后旧选择保留并显示失效，不自动更换模型；迟到测试不能激活新修订。保存新修订后清除页面旧测试详情，持久历史结果不改写。
- 系统配置、完成测试事实和审计属于平台，不随创建者删除。撤权终结该管理员queued/running系统测试，重新授权不能恢复旧任务；领取、外发、提交均检查执行资格。预览后新增在途任务使旧撤权确认失效。
- 多管理员编辑受修订约束，重复创建同键只落一份配置；审计失败回滚配置与幂等命令。系统审计记录操作者、时间、配置类型及结果，密钥不进入响应、事件或审计。
- 个人/系统设置分别保留草稿和未知请求状态，导航往返不丢失。丢失POST响应核查同一命令；丢失PATCH响应只读取当前配置，不误重写。新增导航在移动端换行。

## 复现验收

使用README已有隔离演示入口；终端Node必须为24.x。以下命令在仓库根目录运行：

```sh
python3 scripts/engineering.py build
python3 scripts/engineering.py demo --postgres-bin /opt/homebrew/opt/postgresql@17/bin
```

打开输出的本机`/workspace`；首次注册管理员，在另一浏览器上下文注册普通用户。

1. 管理员进入“系统LLM”，保存配置，确认密钥不回显、保存不发起模型调用。
2. 发现模型或手填模型ID，勾选费用提示后显式测试；通过后普通用户刷新模型选择，看到“系统 / 配置 / 模型”。真实手动测试会访问所填Provider并可能产生费用；自动验证使用FakeProvider。
3. 普通用户显式选择并刷新页面，原选择恢复；没有系统管理入口。管理员修改配置，用户刷新模型选择后看到原模型失效而不是自动替换。
4. 在个人与系统配置之间编辑未保存草稿并往返，草稿各自保留。未知响应、撤权竞态和删除创建者场景用以下隔离自动测试重现。

```sh
PYTEST_ADDOPTS='-k "test_sl or test_sb"' backend/.venv/bin/python scripts/run_storage_tests.py --postgres-bin /opt/homebrew/opt/postgresql@17/bin
python3 scripts/engineering.py check
```
