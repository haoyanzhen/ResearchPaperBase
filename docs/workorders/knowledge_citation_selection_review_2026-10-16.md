# 知识引用与版本选择设计细化及评审

文档版本：v1.0
更新日期：2026-10-16

## 1. 授权与范围

用户授权继续细化跨知识库引用有效性与用户版本选择，使用此前建议，经 subagent 评审修订后加入设计。本轮是文档设计，不实现服务、SQL、迁移或前端。保留现有未提交改动，不重做已确认的不可变快照和状态机设计。

现行新增规则由 [领域 §2.6–2.7](../design/02-02_construction_versioning_appendix.md#26-引用有效性与跨版本重新引用) 维护；需求同步 FR-018/031，UI 由 [P30/P35](../design/03-04_ui_shared_interactions_appendix.md#p35) 承接，DTO 由 [API §5.1](../design/04-01_p0_operation_contracts.md#51-版本摘要与引用解析补充) 维护，服务/数据由 06 §3.2、07 §5.4 承接，验收见 [09 §4.2](../design/09_quality_observability.md#42-引用有效性与版本选择验收)。

## 2. 专项 subagent 评审与采纳

| 评审 | 发现 | 修订 |
| --- | --- | --- |
| citation_review：引用边界只读审查 | FR-031 把旧版本与缺失并列；图谱更新可被误读为修复原引用；EvidenceRef 缺修订目标 | 旧版正常解析；临时故障重试原引用；构建新图谱不替换历史；新增类型化证据目标与独立动态解析投影 |
| citation_review | 可解析性不等于论断支持；同 DOI/哈希和跨项目权限不等于目标成员 | 分开可访问性/完整性/风险/支持性；目标版本生成新引用，来源只作追溯；不继承人工确认，不新增跨 Project 混合能力 |
| selection_review：选择交互只读审查 | 版本卡片事实不足；本轮检索窗口不等于累计覆盖；显式选择后省略版本会漂移 | 补范围/文本来源计数/动态可用性和风险；未知与 0 分开；revision_only/no_change 不伪造截止；显式 ID 及观测时间 |
| selection_review | 最新不等于最佳；固定范围不等于截止认证 | 按任务说明默认版本，历史研究保持原版；变更比较固定 from/to；目标按钮显示所选版本，浏览不改绑定 |

不采用智能质量评分、自动语义匹配/引用迁移、跨 Project 联合检索或私有资产自动复制。API-E01 严格引用覆盖细则与 E03 空版本消费门槛仍待决；没有把它们标记关闭。P1/P2、详细章节影响分析保持现有边界。

## 3. 独立复核

final_audit 已对落盘后的领域、需求、UI、API、服务、数据和验收进行独立只读复核，结论：未发现需修正的问题。复核确认引用身份/授权/完整性/风险/支持性分离、类型化目标约束、并发显式选择、累计范围与未知统计口径一致，P1/P2 及 E01/E03 边界未被改变。该结论不构成实现验收。

## 4. 验证与限制

已执行临时文档检查脚本：10 份文档版本/日期、92 处本地文件链接、7 处新增边界锚点、KV-C01–C05/KV-V01–V05 共 10 个唯一验收编号均通过；限定本轮 10 份文件的 git diff --check 通过。链接检查针对目标文件存在及新增边界锚点，不声称全库历史锚点全部核验。临时脚本仅供本轮检查，不是应用测试入口。未执行应用、数据库、外部服务或端到端验收；新增矩阵是后续测试要求，不是已通过结果。
