## 错误适用性与兼容方向

| 状态 | 适用及依据 |
| --- | --- |
| 400 | VALIDATION_BAD_REQUEST，请求格式/必要头无效；不含游标。 |
| 401 | AUTH_REQUIRED/SESSION_INVALID/ACCOUNT_DISABLED，当前会话；不含登录凭证错误。 |
| 403 | PERMISSION_CSRF_REJECTED；普通用户创建不是管理员操作。 |
| 404 | PERMISSION_RESOURCE_UNAVAILABLE，只在原结果已删除/不再可见等重放场景；不披露旧Project。 |
| 409 | STATE_IDEMPOTENCY_CONFLICT，同键异参；新建无对象修订、确认、知识版本或构建槽。 |
| 413/415 | VALIDATION_PAYLOAD_TOO_LARGE/UNSUPPORTED_FORMAT，请求体大小与格式拒绝；不引入上传处理。 |
| 422 | VALIDATION_FIELD_INVALID/UNKNOWN_FIELD；不含文件不可读。 |
| 429 | STATE_RESOURCE_LIMIT，技术资源保护及Retry-After；不增加产品配额。 |
| 500 | STORAGE_INTERNAL_FAILURE，受理/存储故障或未知提交结果安全投影。 |

复用A04安全错误组件，没有模型/论文/邮件调用，因此不绑定Provider 502/503/504；没有已有目标修订/确认前置，不绑定412/428及相关409。结构只描述允许投影，不证明运行鉴权、错误选择或无副作用。

实际入场JSON另存[before.openapi.json](evidence/task014_b01_2026-10-24/before.openapi.json)。本轮修改既有POST /projects：请求幂等键排除非打印字符（修复尾换行被`$`接受）；响应meta从通用可null收紧为完成结果非null；必需Location/no-store声明与适用错误状态补全。新增ProjectCreateMeta不改通用IdempotentMeta。保守兼容检查实际退出1，仅报告`operation changed/removed: POST /projects`，见[兼容日志](evidence/task014_b01_2026-10-24/compatibility.log)；非零，必须保留真实结果供人工审核，不称自动兼容通过；其他操作与共享schema应保持字节语义相同。
