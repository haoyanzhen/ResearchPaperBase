## 整体布局结构

系统采用**左侧导航 + 右侧内容区**的两栏布局。左侧导航栏全局固定，内容区根据当前页面和模式动态渲染。

```
┌──────────────────────────────────────────────────────────────────────┐
│  TOPBAR：Logo   [当前项目名 ▼]   ── 模式切换 ──   [设置] [头像]      │
├───────────┬──────────────────────────────────────────────────────────┤
│           │                                                          │
│  SIDEBAR  │                   CONTENT AREA                          │
│  (固定)   │                   (随路由切换)                           │
│           │                                                          │
│           │                                                          │
└───────────┴──────────────────────────────────────────────────────────┘
```

**Topbar 说明：**
- 左侧：系统 Logo
- 中部：当前项目名称（下拉可切换项目，或点击进入项目列表）
- 模式切换区：三个标签按钮（构建 / 深度研究 / 综述），当前模式高亮
- 右侧：全局设置入口、用户头像（含退出）

**Sidebar 内容随当前模式变化：**

| 构建模式 | 深度研究模式 | 综述模式 |
|---------|------------|---------|
| 构建流程 | 对话列表 | 综述架构 |
| 论文库 | 知识图谱 | 章节列表 |
| 检索历史 | 研究历史 | 版本管理 |
| 定时设置 | - | - |

## 交互状态说明

### 模式切换标签状态

| 状态 | 外观 |
|------|------|
| 当前模式 | 高亮填充背景 |
| 可切换（有论文库） | 正常显示，可点击 |
| 不可切换（论文库为空） | 灰色 + 锁图标 🔒，悬停提示 |
| 有运行中任务 | 正常显示，点击弹确认弹窗 |

### 构建阶段步骤状态

| 状态 | 图标 |
|------|------|
| 未开始 | ○ 灰色 |
| 运行中 | ● 蓝色 + 动画 |
| 等待用户交互 | ● 橙色（暂停） |
| 已完成 | ✓ 绿色 |
| 失败 | ✗ 红色 |

### SSE 流式输出

- LLM 正在输出时，消息气泡末尾显示光标动画 `█`
- 构建任务进行中时，进度条实时更新
- 任务完成时弹出 Toast 通知
